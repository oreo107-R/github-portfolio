
# Database Management Project

## Project Overview

This project was developed as part of my Computer
Information Systems coursework at Lamar University.

The project demonstrates relational database design,
SQL programming, and database management using MySQL.

## Technologies Used

- MySQL
- MySQL Workbench
- SQL

## Database Structure

The database contains three main tables:

- Department
- Employee
- SalaryLog

## Features

- Primary and foreign key relationships
- Data integrity constraints
- Stored procedures
- SQL views
- Database triggers
- Salary change tracking
- Error handling

## Learning Outcomes

Through this project, I gained experience in
relational database development, SQL programming,
data integrity, and database automation.
