
# Dino Learner - Educational Android Game

## Project Overview
Dino Learner is a dinosaur-themed educational
Android game designed to help children develop
early learning skills through interactive gameplay.

## Technologies
- Kotlin
- Android
- Jetpack Compose

## Features
- Dinosaur-themed user interface
- Player profile selection
- Multiple learning levels
- Letter matching activities
- Interactive scoring system
- Audio replay controls
- Unlockable levels
